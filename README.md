## 怎么买季付？之后能改成年付吗？

**新购**：进入套餐购买页，在 Billing Cycle 下拉菜单里选 Quarterly，页面价格会自动切换成季付价，确认后走正常下单流程即可。付款支持支付宝（Alipay）和银联，国内用户不需要外币信用卡。

**已购用户改周期**：登录搬瓦工后台，进入 Services → My Services 找到对应套餐，点击 Billing 后面的 Modify，选择目标周期并确认新价格。改周期有两个限制要提前知道：

1. 只能从短周期改成长周期（月付 → 季付 → 半年付 → 年付），不能反向。季付可以改年付，但改不了月付。
2. 改完之后按**当前官方售价**重新计算，不保留你当初的购买价。搬瓦工续费虽然不涨价，但改周期走的是重新计价——如果官方价格已经上调，一改就按新价算。早年低价入手的套餐，直接续费比改周期划算。

## 季付到期会自动续费吗？

会。搬瓦工默认到期自动续费：到期后系统生成续费订单，账户余额充足就直接扣款续上。不想自动续的，可以在后台手动关闭续费。

想一次锁定多年也有办法：往账户里充值余额，到期自动扣。比如 CN2 GIA-E 20G 年付 $169.99，余额充到 $510 左右，之后三年就会逐年自动扣款续费，省得每年惦记。不过既然续费本身不涨价，充值多年省下的其实是“忘记续费导致停机”的风险，不是钱。另外注意，充值只支持信用卡和 PayPal，不能用支付宝。
